KETA SCAN

📷 ماسح الباركود

الباركود المباشر

متصل مباشر
بانتظار المسح...
""") readme = dedent(""" # KETA Scan موقع قارئ باركود مباشر بين الجوال والآيباد. ## التشغيل 1- ثبت Node.js 2- افتح التيرمنال داخل المشروع 3- ثبت المكتبات: npm install 4- شغل السيرفر: npm start 5- افتح: http://localhost:3000 ## المميزات - قراءة باركود بالكاميرا - بث مباشر للأجهزة - تصميم احترافي - صوت عند المسح - يعمل على الجوال والآيباد """) (base / "server.js").write_text(server_js, encoding="utf-8") (base / "package.json").write_text(package_json, encoding="utf-8") (base / "README.md").write_text(readme, encoding="utf-8") public = base / "public" public.mkdir(exist_ok=True) (public / "index.html").write_text(index_html, encoding="utf-8") zip_path = "/mnt/data/KETA-Scan.zip" with ZipFile(zip_path, "w") as zipf: for file in base.rglob("*"): zipf.write(file, file.relative_to(base.parent)) print(f"Created: {zip_path}")
